# Swifto Keycloak Theme Builder

This repository builds a Keycloak login theme with Keycloakify, React, Vite, Tailwind CSS 4, and the shadcn-based `@oussemasahbeni/keycloakify-login-shadcn` extension.

The current generated theme is `swifto`. The implementation keeps the shadcn page coverage and components, then layers the Swifto brand, colors, typography, and split login shell on top.

## Commands

```bash
yarn install
yarn dev
yarn run build
yarn run build-keycloak-theme
```

`yarn install` runs `keycloakify sync-extensions`, which refreshes generated shadcn files under `src/login` and `src/components`.

## Customization Rules

Most shadcn extension files are generated and ignored by git. Before editing one of those generated files, claim ownership so the next sync does not overwrite it:

```bash
npx keycloakify own --path "login/index.css"
```

Owned files are listed in `src/.gitignore`. The Swifto skin currently owns:

- `login/index.css`
- `login/components/Template/Template.tsx`

Keep app-specific content in `src/login/themeConfig.ts` when possible. That file is not generated by the extension and is the intended place to add future client/application variants.

## Adding More Client Themes

1. Add the Keycloak theme name in `vite.config.ts`:

```ts
keycloakify({
    themeName: ["swifto", "next-client-theme"],
    accountThemeImplementation: "none"
});
```

2. Add a matching entry in `src/login/themeConfig.ts` with the client name, tagline, hero copy, and visual asset.

3. Run a build so `src/kc.gen.tsx` is regenerated from the Keycloakify config:

```bash
yarn run build
```

4. Build the Keycloak artifact:

```bash
yarn run build-keycloak-theme
```
